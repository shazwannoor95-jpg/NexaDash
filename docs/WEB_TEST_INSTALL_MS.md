# Cuba fullscreen pada head unit — NexaDash Web Test1.0

[Download APK](https://raw.githubusercontent.com/shazwannoor95-jpg/NexaDash/nexadash-native-panel-experiment/dist/web-test/NexaDash-WebTest-1.0.apk) (~21KB).

Install sebagai **app baharu** bernama **NexaDash Web Test**. Package berbeza, bukan update atau pengganti Native Lab. App lama, default launcher dan datanya tidak diubah. Jika diminta, benarkan browser/file manager memasang APK. Buka ikon NexaDash Web Test daripada Apps.

1. Tekan **Start YouTube web** dalam panel kiri.
2. Cari video biasa dan mula main. Internet dan WebView yang berfungsi diperlukan.
3. Tekan ikon fullscreen pada player YouTube.
4. Tekan **Exit fullscreen** atau Android **Back**; semak video kembali ke panel.
5. Ulang masuk/keluar fullscreen. Cuba keluar app dan buka semula; tekan Start jika mahu memuatkan YouTube lagi.

Jika gagal, hantar rakaman dari sebelum menekan fullscreen sehingga selepasnya. Catat sama ada video/audio terus berjalan, skrin hitam, atau mesej error. Jangan masukkan akaun/login dalam rakaman yang dikongsi. Video yang memerlukan sign-in/restrictions boleh tidak tersedia dalam web player.

Ini ujian web fullscreen sahaja, bukan Radio FM atau TizenTube native. Build/signature/alignment/manifest telah diperiksa; ujian playback/fullscreen pada head unit belum dibuat oleh proses build.

APK menggunakan kunci baharu khusus Web Test. Backup private keystore/password disediakan secara peribadi dalam sesi kerja, bukan di GitHub. Simpan backup itu pada komputer sendiri untuk membolehkan update Web Test pada masa depan. Ia tidak memulihkan kunci Native Lab lama.
